# Luca 6 – Performance

GitHub-Pages-Version der Trainings-App.

## Veröffentlichung

1. Neues öffentliches GitHub-Repository erstellen, zum Beispiel `luca-6-performance`.
2. Alle Dateien aus diesem Ordner in das Repository hochladen.
3. Unter **Settings → Pages** bei **Source** `Deploy from a branch` auswählen.
4. Branch `main` und Ordner `/(root)` auswählen und speichern.
5. Danach erscheint die Internetadresse der App im Bereich **Pages**.

## iPhone

Den veröffentlichten Link in Safari öffnen, unten auf **Teilen** und anschließend auf **Zum Home-Bildschirm** tippen.

Hinweis: Die Daten werden zunächst lokal auf jedem Gerät gespeichert. Eine gemeinsame Synchronisierung zwischen zwei iPhones benötigt später eine Cloud-Datenbank.
