# LUCA6 – Road to Pro v5

## GitHub Pages aktualisieren
1. Den Inhalt dieses Ordners öffnen.
2. Alle Dateien und Ordner in das GitHub-Repository `luca-6-performance` hochladen.
3. Vorhandene Dateien ersetzen.
4. 1–3 Minuten warten und die GitHub-Pages-Seite neu laden.
5. Auf dem iPhone die alte Home-Bildschirm-App löschen und die Seite in Safari erneut über „Teilen > Zum Home-Bildschirm“ hinzufügen.

## Strava
Die Client-ID ist bereits in `config.js` eingetragen. Das Client-Secret darf niemals in GitHub stehen. Für die vollständige Verbindung wird ein sicherer Backend-Dienst benötigt. Die Vorlage befindet sich in `worker/strava-worker.js`.
